# Fix&Spacebook

Platforma uslug lokalnych w Polsce.

Laczy osoby szukajace pomocy z osobami i firmami wykonujacymi uslugi.

## Cel

Pomoc w znalezieniu wykonawcy legalnej i konkretnej uslugi.

Przyklady uslug:
- naprawy samochodow
- naprawy rowerow
- naprawy AGD i RTV
- sprzatanie
- prace ogrodowe
- przeprowadzki
- opieka nad zwierzetami

## Pierwsza wersja

- dodawanie zlecen
- przegladanie ogloszen
- kategorie i lokalizacja
- profil klienta lub wykonawcy
- odpowiedz na zlecenie
- zglaszanie naruszen
